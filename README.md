# 🔍 GitHub User Search App

A simple and responsive web application to search and display GitHub users using the GitHub Public API.  
Built with **HTML, CSS, and JavaScript**.

This project is beginner-friendly and helps you learn how to work with APIs and frontend design.

## ✨ Features

✅ Search for GitHub users  
✅ Shows multiple related profiles  
✅ Clean and modern UI  
✅ Smooth animations and transitions  
✅ Responsive design (works on mobile & desktop)  
✅ Direct link to user profiles  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- GitHub Public API

## 📖 How to Use

1. Open the website
2. Enter a username or keyword
3. Click **Search** (or press Enter)
4. View related GitHub profiles
5. Click **View Profile** to open user page

---

## ⚙️ Setup (Run Locally)

To run this project on your computer:

1. Download or clone this repository
2. Open `index.html` in any browser

Or use Live Server in VS Code.

---

## 🌐 API Used

This project uses the GitHub Search Users API:

https://api.github.com/search/users?q=USERNAME
